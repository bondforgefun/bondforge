# BondForge Public Testnet Site

这是 BondForge 的 BSC 测试网站点包。

## 当前页面

- 首页
- 发布项目
- 项目详情页
- NFT 市场
- 控制台
- 白皮书
- FAQ
- 联系页

## 当前产品表达

- 募资阶段先使用认购凭证，可退款
- 项目打满并发射后再统一分发 NFT
- 退款 fee 固定为 1%
- 支持两种 NFT 类型：
  - 调用项目方自己的 NFT 元数据
  - 上传 Meme 图像生成同款 NFT
- 项目详情页展示图片、名称、社媒和 CA
- 站内保留燃烧池入口与 NFT 市场

## 本地运行

```bash
npm install
npm run dev
```

这版优先保证公开测试站的页面结构与文案逻辑，方便继续在 v0 / GitHub 上迭代。
